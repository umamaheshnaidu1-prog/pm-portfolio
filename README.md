# Product Management Portfolio — Free Starter

A responsive, zero-build portfolio website. No paid dependencies, API keys, or subscriptions required. Google Fonts is optional; local fallback fonts work without it.

## Preview
Open `index.html` in a browser. For a local server, run `python -m http.server 8000` in this folder, then open http://localhost:8000.

## Publish to GitHub Pages (free)
1. Sign in to https://github.com and create a **public** repository named `pm-portfolio`.
2. Choose **Add file → Upload files** and upload `index.html`, `styles.css`, `script.js` (and optionally this README). Commit changes.
3. Open **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Once deployed, open `https://YOUR-USERNAME.github.io/pm-portfolio/`. Deployment can take several minutes.

## Customize before sharing with recruiters
- Confirm your preferred public name and all project claims.
- Update the SaathiPay prototype URL in `index.html` if it changes.
- Add links to your actual Bugasura and SnapOrderAI case studies when ready. The current labels are intentionally not clickable.
- Add your resume PDF and a download button when you have the final version; don't upload a private document accidentally.
- Add an email contact link only if you want your email publicly visible.
- Expand each project into an evidence-backed case-study page with problem, research, trade-offs, solution, metrics, and outcomes.

## Notes
GitHub Pages is intended for static websites; this starter uses no server, database, or paid service. The artwork is generated with CSS, not external copyrighted assets.
